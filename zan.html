Bab 7: Struktur Data Array dan Record dalam Pascal

1. Konsep Dasar Array

Array didefinisikan sebagai suatu kumpulan dimana elemen-elemennya berjenis data sama (homogen). Suatu array dapat dibedakan atas 2 bagian, yaitu array berdimensi satu dan array multi dimensi.

  • Array Dimensi Satu: Dapat dikatakan sebagai suatu daftar yang linier atau sebuah kolom.
  • Array Multi Dimensi: Dapat dianggap sebagai sebuah matriks yang jumlah kolomnya lebih dari satu.
{ Bentuk Umum Deklarasi Array 1 Dimensi }
VAR nama_array : ARRAY [index] OF jenis_elemen; 

{ Contoh }
VAR x : ARRAY [1..10] OF integer;
{ Bentuk Umum Deklarasi Array 2 Dimensi }
VAR nama_array : ARRAY [indeks_baris, indeks_kolom] OF jenis;

{ Contoh: Matriks 3 Baris, 4 Kolom }
VAR A : ARRAY [1..3, 1..4] OF integer;

2. Memproses Array

Untuk keperluan membaca variabel array (input) kita tidak bisa melakukan seperti sebuah data bernilai tunggal, yaitu READ(X). Sebab jika kita membaca variabel berjenis array berarti kita membaca elemen-elemen array tersebut.

Untuk itu diperlukan suatu bentuk perulangan (seperti FOR..DO).

{ Tentukan integer terbesar dari 10 bilangan }
PROGRAM MAKS;
VAR 
  B : ARRAY [1..10] OF integer;
  I, J, MAX : integer;

BEGIN
  FOR I := 1 TO 10 DO READ(B[I]);
  MAX := B[1];

  FOR J := 2 TO 10 DO
    IF MAX <= B[J] THEN MAX := B[J];
  
  WRITE(MAX);
END.

3. Konsep Dasar & Proses Record

Record dapat dikatakan sebagai suatu kumpulan data item yang masing-masing mempunyai jenis data berbeda (heterogen). Data item yang merupakan elemen record biasanya disebut dengan FIELD.

Selain menyebutkan field designator (contoh: a.bag_nyata), untuk memproses suatu record dapat digunakan statement WITH agar penulisan lebih sederhana.

TYPE x = RECORD
    No : integer;
    Kode : char;
    Juml : integer;
    Harga : real;
END;
VAR p, q : x;

{ Membaca variabel memanfaatkan statement WITH }
WITH p, q DO 
  READ(no, kode, juml, harga);
