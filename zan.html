Bab 7: Struktur Data Array dan Record dalam Pascal

1. Konsep Dasar Array

Array didefinisikan sebagai kumpulan data item yang masing-masing mempunyai jenis data berbeda[cite: 1, 2]. Elemen array bersifat homogen, yaitu semua elemennya memiliki tipe data yang sama[cite: 2, 5].

  • Array Dimensi Satu: Dapat dikatakan sebagai suatu daftar yang linier atau sebuah kolom[cite: 3].
  • Array Multi Dimensi (Contoh: Dimensi Dua): Dapat dianggap sebagai sebuah matriks yang jumlah kolomnya lebih dari satu[cite: 6].
{ Bentuk Umum Deklarasi Array 1 Dimensi }
VAR nama_array : ARRAY [index] OF jenis_elemen; [cite: 4]

{ Contoh }
VAR x : ARRAY [1..10] OF integer; [cite: 5]
{ Bentuk Umum Deklarasi Array 2 Dimensi }
VAR nama_array : ARRAY [indeks_baris, indeks_kolom] OF jenis; [cite: 7]

{ Contoh: Matriks 3 Baris, 4 Kolom }
VAR A : ARRAY [1..3, 1..4] OF integer; [cite: 8, 9]

2. Memproses Array

Untuk keperluan membaca variabel array (input) kita tidak bisa melakukan seperti sebuah data bernilai tunggal, yaitu READ(X)[cite: 11]. Kita harus membaca elemen-elemen array tersebut[cite: 12].

Untuk itu diperlukan suatu bentuk perulangan[cite: 13]. Demikian pula halnya untuk keperluan memproses elemen-elemennya, harus ditunjukkan elemen yang akan diproses[cite: 14].

{ Tentukan integer terbesar dari 10 bilangan dalam array B }[cite: 15]
PROGRAM MAKS;
VAR 
  B : ARRAY [1..10] OF integer;
  I, J, MAX : integer; [cite: 16]

BEGIN
  FOR I := 1 TO 10 DO READ(B[I]);
  MAX := B[1]; { Inisialisasi awal dengan elemen pertama } [cite: 17]

  FOR J := 2 TO 10 DO
    IF MAX <= B[J] THEN MAX := B[J];
  
  WRITE(MAX); [cite: 18]
END.
{ Menghitung rata-rata dari 10 bilangan }[cite: 19]
PROGRAM RATA_RATA;
TYPE INDEKS = 1..10;
VAR 
  A : ARRAY [INDEKS] OF INTEGER; [cite: 20]
  I, TOTAL : INTEGER;
  RATA2 : REAL; [cite: 21]

BEGIN
  TOTAL := 0;
  FOR I := 1 TO 10 DO
  BEGIN
    READ(A[I]); [cite: 22]
    TOTAL := TOTAL + A[I];
  END;

  RATA2 := TOTAL / 10;
  WRITE(RATA2); [cite: 23]
END.

3. Konsep Dasar Record

Record dapat dikatakan sebagai kumpulan data item yang masing-masing mempunyai jenis data berbeda[cite: 24]. Data item yang merupakan elemen record biasanya disebut dengan FIELD[cite: 25].

{ Bentuk Umum Deklarasi Variabel Berjenis Record }[cite: 26]
VAR nama_record : RECORD
    Nama_field_1 : jenis; [cite: 26]
    Nama_field_2 : jenis;
END; [cite: 27]

{ Contoh }
TYPE date = RECORD
    Tanggal : 1..31;
    Bulan   : 1..12; [cite: 29]
    Tahun   : 1900..2000;
END; [cite: 30]
VAR event1, event2 : ARRAY [1..10] OF date; [cite: 30]

4. Memproses Record & Statement WITH

Untuk memproses variabel berjenis record, dilakukan dengan menyebutkan field designatornya: Nama_record.nama_field[cite: 34].

Selain cara tersebut, untuk memproses suatu record dapat digunakan statement WITH. Dengan statement ini penulisannya akan lebih sederhana[cite: 39, 40]. Bentuk umum penulisan statement WITH adalah: WITH nama_record DO statement[cite: 40].

{ Penjumlahan dua bilangan kompleks }[cite: 35]
PROGRAM contoh;
TYPE bk = RECORD
    Bag_nyata : integer;
    Bag_imajiner : integer;
END;
VAR a, b, c : bk; BEGIN
  { Membaca input, menyebutkan field satu per satu }
  READ(a.bag_nyata, a.bag_imajiner, b.bag_nyata, b.bag_imajiner);
  
  c.bag_nyata := a.bag_nyata + b.bag_nyata; 
  c.bag_imajiner := a.bag_imajiner + b.bag_imajiner; [cite: 38]
  
  WRITELN(c.bag_nyata, '+i', c.bag_imajiner); [cite: 39]
END.
{ Contoh Membaca Variabel Berjenis Record dengan WITH }[cite: 40]
TYPE x = RECORD
    No : integer; [cite: 40]
    Kode : char;
    Juml : integer;
    Harga : real;
END;
VAR p, q : x; [cite: 41]

BEGIN
  { WITH p,q DO akan membaca variabel no, kode, juml, harga langsung }
  WITH p,q DO 
    READ(no, kode, juml, harga); [cite: 42]

  { Bandingkan jika digunkaan cara TANPA WITH: }
  { Read(p.no, p.kode, p.juml, p.harga, q.no, q.kode, q.juml, q.harga); }[cite: 43]
END.
